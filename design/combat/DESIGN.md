# Refillit 戰鬥設計稿：灰色世界的委託

2026-10-21 草案。畫面草圖：`design/battle-mock/side.html`（定案的 B 版，成品圖 `mock-side.png`）。
第一版上下排列的草圖 `index.html`／`mock.png` 留著對照。

標記說明：**定案**＝已經跟使用者確認過；**草案**＝我的建議，還可以改；**待定**＝還沒討論。

---

## 1. 世界觀（定案）

- **這個世界很 blue**。blue 有兩層意思：心情低落（feeling blue），還有我們 UI 的丹寧藍。
- 日常生活裡讓人累的**現實東西被吸走了顏色，變成灰色的怪物**，不停阻撓大家獲得 chill。例如鬧鐘、未讀通知、月底帳單。
- **咖啡廳是這個世界少數還有顏色的地方**。像素場景裡的焦糖木頭、咖啡和暖光，本身就是設定的一部分。
- 灰色世界的**居民**也被 blue 困住了。他們會到店裡**發委託**，請店員出門討伐或探索。
- 打贏之後，怪物會**恢復顏色**，變回普通的東西。

畫面語言沿用「丹寧拼貼」：
- 灰色世界：灰色半調照片，加上幾何零件（軌道線、灰圓盤、白星、× 眼睛、故障切片）。
- 我方：像素角色，站在有顏色的木板上。
- 珊瑚色只用在事件、警示和錢，例如敵人的蓄力大招和偷錢。

## 2. 核心循環（草案）

```
 開店經營 ──做飲料──▶ 戰鬥道具（藥水）
    ▲                      │
    │                      ▼
 素材 / 配方 / 裝潢 ◀── 外出日打委託
 金錢 / 器具 / 新卡
```

兩邊要**互相需要**，不能讓玩家只挑效率高的一邊玩：
- **店裡 → 戰鬥**：出門前要先在店裡把飲料做好帶著。
- **戰鬥 → 店裡**：
  - 素材可以解鎖新飲品、升級菜色。
  - 恢復顏色的怪物變成店裡的裝潢，以後可以接上裝潢魅力係數。
  - 完成委託的居民之後會來店裡當客人。

## 3. 外出日（定案）

| 規則 | 內容 |
|---|---|
| 公休 | 外出日佔掉**一整輪（2 小時）**，那一輪店不營業 |
| 成本 | 員工不領薪水，**房租照付** |
| 獎勵 | 整趟委託的總價值約為**該輪營收的 1.5 倍** |
| 次數 | **外出券每天發 1 張，最多存 3 張**（每個在地日曆日重置，跟 Today 同一套時間） |
| 開始 | 一定要**上線按下出門**才開始。那一輪記為公休，離線結算看得到 |
| 時間限制 | 這一輪 2 小時內什麼時候打都可以。輪次結束時，還沒打的關卡作廢，已經拿到的獎勵照算 |
| 掃蕩 | 打過的委託類型和難度可以掃蕩。掃蕩一樣要用一張外出券、一樣公休 |

「該輪營收」的算法（草案）：
- 用 `offline.js` 的 `MODEL` 和 `capacity()` 估算這家店一輪的預期營收。伺服器也有同一份程式，所以兩邊算得出同一個數字。
- 委託的獎勵表以這個數字為基準。

## 4. 委託（定案方向，細節是草案）

### 委託板
- 每個真實日刷新，隨機出 **3 張委託**。每張寫著：委託人、一句話的小故事、類型、難度、環境修正、敵人弱點提示、主要獎勵。
- 用一張外出券接一張委託。
- 隨機結果用「日期 + 玩家」當種子，由伺服器決定。**重新整理頁面也刷不出別的委託**，避免玩家重刷挑獎勵。

### 兩種委託
| | 討伐委託 | 探索委託 |
|---|---|---|
| 路線 | 3～4 場戰鬥，最後打 Boss | 5～6 格的分岔地圖，格子類型見下表 |
| 主要獎勵 | 金錢、器具 | 素材、新配方、新卡 |
| 適合 | 想打架、想快點拿錢 | 想看居民的小故事、碰運氣 |

### 路線格子（殺戮尖塔的地圖）
| 格子 | 內容 |
|---|---|
| ⚔ 戰鬥 | 一般戰鬥 |
| ◆ 菁英 | 比較難，掉落一定有器具或稀有素材 |
| ? 居民事件 | 二選一的小事件，可能拿到卡、素材，或付出 CHILL 換好東西 |
| ▣ 寶箱 | 直接拿素材或小物 |
| ☕ 咖啡站 | 二選一：回復 CHILL，或把一張卡升級 |
| ✦ Boss | 委託的目標 |

### 環境修正
每張委託最多帶一個修正，例如：
- **雨天**：雨傘系敵人變強。
- **夜間**：下午 7 點後開始的輪次，沿用店裡的 `NIGHT_FROM`。Bbaekko 怕黑，在夜間打得比較弱。
- **星期一**：只在真實的星期一出現，Boss 會換成「星期一」。

## 5. 戰鬥規則：殺戮尖塔輕量版（草案）

設計原則：**想的時間放在出門前，戰鬥中每回合只做幾個小決定**。回合制會等玩家，搭車時隨時可以放下手機。

### 隊伍
- **出門帶 4 個員工**。
- 全隊**共用一條血：CHILL 值**，起始 60，之後隨咖啡廳等級成長（數值待定）。
- 因為共用一條血，**沒有單一角色倒下**的情況，CHILL 歸零就整隊撤退。
- **奶泡護盾**就是殺戮尖塔的格擋：先吸收傷害，回合結束時消失。

### 牌組與回合
| 項目 | 數值 | 原版殺戮尖塔 |
|---|---|---|
| 牌組 | 每人帶 3 張，共 **12 張** | 起始 10 張，之後越疊越厚 |
| 手牌 | 每回合**補到 3 張**，沒出的牌留在手上 | 每回合抽 5 張，回合結束全部棄掉 |
| 能量 | 每回合 **3 點** | 3 點 |
| 一場長度 | 3～5 回合 | 不一定 |

一個回合的順序：
1. 補牌到 3 張，能量回到 3。
2. 玩家出牌：點卡片，再點目標。不需要目標的卡直接點就生效。
3. 按「結束回合」。
4. 敵人照順序執行頭上的意圖。

還有兩個按鈕：
- **自動**：由程式出牌。
- **2 倍速**：加快動畫。

### 敵人意圖
- 敵人**永遠顯示這回合要做什麼**，例如「攻擊 8」「蓄力 · 全體 18」「偷 12 金幣」「干擾 · 費用 +1」。
- 一般意圖用墨色。蓄力大招和偷錢這種要玩家注意的，用**珊瑚色**。
- Cheetie 在隊上時，可以**多看一回合**（讀心）。

### 褪色條（取代星鐵的韌性條）
- 每張攻擊卡除了傷害，還有「褪色」數值。
- 褪色條填滿時，怪物**恢復顏色一回合**：這回合不行動，而且玩家出牌效果加倍。之後褪色條歸零，重新累積。
- 格子填的是咖啡廳的暖色（焦糖、奶油、蜜桃），代表顏色回來了。
- 怪物血量歸零就**永久恢復顏色**，有機率變成裝潢掉落。

### 飲料（藥水）
- 最多帶 **2 杯**，出門前從店裡的庫存挑。
- 喝飲料不花能量，每杯用一次就沒了。

| 飲料 | 效果（草案） |
|---|---|
| 濃縮咖啡 | 這回合能量 +2 |
| 熱可可 | 回復 12 CHILL |
| 冰咖啡 | 清除所有負面效果 |
| 抹茶拿鐵 | 全體敵人褪色 +3。Cheetie 在隊上時效果減半，因為她討厭抹茶 |
| 可頌 | 抽 2 張牌 |

### 撤退與失敗
- CHILL 歸零就撤退。這張委託算失敗，但**路上已經拿到的獎勵照算**。外出券照樣消耗。
- 員工會有一點點挫折感（例如精力 −10，數值待定）。這個懲罰要輕，因為輸了已經損失了一輪營收。

## 6. 角色卡（草案）

卡牌從店裡現有的角色技能長出來（`KITS`，`src/data.js`），讓角色的個性在戰鬥裡一樣看得出來。每個角色：
- 有 **3 張起始卡**。
- 有 **1 個被動**，只要在隊上就生效。
- 委託可以**解鎖更多卡**。出門前從自己的卡池挑 3 張帶出去。

### Mocha Latte：時間控制
| 卡 | 費用 | 效果 |
|---|---|---|
| **時間暫停** | 2 | 一個敵人這回合的意圖作廢 |
| 拿鐵一擊 | 1 | 6 傷害，褪色 +1 |
| 咖啡因加速 | 1 | 抽 1 張，這回合下一張攻擊卡傷害 +3 |

被動「咖啡因光環」：第一回合能量 +1。

### Cheetie：速度與讀心
| 卡 | 費用 | 效果 |
|---|---|---|
| **衝刺連擊** | 1 | 4 傷害 ×2，褪色 +1 |
| 讀心術 | 0 | 抽 1 張 |
| 側身閃過 | 1 | 獲得 6 奶泡護盾 |

被動「讀心」：可以看到敵人下一回合的意圖。

缺點：討厭抹茶，抹茶系飲料在她隊上時效果減半。

### Hee Hee：聚光燈與綻放
| 卡 | 費用 | 效果 |
|---|---|---|
| **聚光燈** | 1 | 獲得 10 奶泡護盾。這回合多段攻擊只算第一段 |
| 綻放 | 1 | 回復 5 CHILL |
| 舞台謝幕 | 2 | 對全體造成 5 傷害 |

被動「開花小費」：這場委託的金幣獎勵 +15%。

### Bbaekko：念錯咒語
| 卡 | 費用 | 效果 |
|---|---|---|
| **念錯咒語** | 1 | 隨機生成一張 0 費的卡。有 10% 機率變成「怪咒」，例如這回合能量 −1 |
| 狂野魔法 | 2 | 對隨機敵人造成 3～15 傷害 |
| 小聲唸咒 | 0 | 褪色 +2 |

缺點：
- 怕黑，夜間委託傷害 −20%。
- 害羞，不能帶 0 費以外的護盾卡（待定）。

### Oritokki：透視
店裡還沒有技能組。先沿用之前「看出快壞掉的設備」的想法，改成戰鬥版：

| 卡 | 費用 | 效果 |
|---|---|---|
| **透視** | 1 | 揭露一個敵人的隱藏弱點，褪色 +2 |

### 其他 5 位
Tata、RJ、Chimmy、Bboogyuli、Bamgeut 在店裡也還沒有技能組（**待定**）。要等使用者給角色設定，再一起設計店裡的技能和戰鬥卡，不要自己編。

## 7. 怪物（草案）

全部是**灰色半調的現實物品**，加上幾何零件。做法跟 UI 拼貼素材一樣：
1. 用 gpt-image-bridge 生成白底黑白棚拍照。
2. 用 `tools/collage_cutout.py` 轉成網點剪影。

草圖裡已經做好了鬧鐘、帳單、手機三張。

| 怪物 | 原本是什麼 | 戰鬥特性 |
|---|---|---|
| 鬧鐘獸 | 早上的鬧鐘 | 蓄力一回合後，下一回合對全體放大招；放完會「睡回籠覺」休息一回合 |
| 未讀通知 | 手機紅點 | 讓玩家下一張牌費用 +1；每 2 回合叫出一隻小通知 |
| 月底帳單 | 月底帳單 | 偷金幣。3 回合內沒打倒就帶著錢跑掉 |
| 雨傘幽靈 | 下雨天 | 雨天和夜間變強 |
| 待辦清單 | 待辦事項 | 每回合多一行，護盾也跟著變厚 |
| 打卡機 | 上班打卡 | 倒數 3 回合，時間到就放全體大招 |
| **星期一**（Boss） | 星期一 | 只在真實的星期一出現 |

設計規則：
- 每隻怪物的意圖模式要**一眼看得懂**，大約 2～3 種動作輪流。
- 每隻怪物都要讓某個角色特別好用。例如鬧鐘蓄力時用 Mocha 的時停，帳單跑掉之前用 Cheetie 的連擊追打。

## 8. 獎勵與成長（草案）

| 類型 | 跟著委託清空 | 永久保留 |
|---|---|---|
| 卡牌 | 路上撿到的卡，只在這趟有效 | 解鎖到角色卡池裡的新卡 |
| 道具 | 路上撿的小物，像殺戮尖塔的遺物，只在這趟有效 | **器具**：每個員工一個欄位，例如拉花杯、磨豆機、Coffee Cane |
| 資源 | — | 金錢、素材、恢復顏色的怪物裝潢 |

- 器具和衣櫃分開：衣櫃維持純外觀，穿搭不用顧慮數值。
- 素材接到配方解鎖和菜色升級。之後要決定跟研習券的關係（**待定**）。
- 第一次通關某種委託和難度時，一定掉新卡或器具；之後再打或掃蕩，只給金錢和素材。

## 9. 畫面（定案：B 版）

直屏，不用轉手機。

```
┌──────────────────────┐
│ 委託標題 · 路線 · 回合   │
│                      │
│  我方 4 人      灰色怪物  │  ← 上半部：斜向舞台
│  （左，面向右）  （右）    │
│  木板        灰色道路    │
│                      │
│ CHILL · 奶泡 · 飲料      │
│ 能量  [卡] [卡] [卡]     │  ← 下半部：拇指區
│ 手動/自動/2×    結束回合  │
└──────────────────────┘
```

- **舞台**：正式版用店裡的像素渲染和描邊（`src/renderer.js` 的像素模式），做成一條灰色世界的街道。
  - 斜向舞台跟店面一樣是 45° 鏡頭。
  - 角色直接用現有的 64px 精靈圖（`src/spriteview.js`），不用重烘。
  - 怪物是有厚度的立牌，不是平貼在畫面上的圖片。
- **角色動作**：大多數現有動作就夠用（Idle、Work、Cheer、Hit）。可能要多烘一個「攻擊」動作（**待定**）。
- **特寫**：2 費以上的招牌卡出牌時，播一段 Persona 風的斜切特寫，沿用 `src/ui/transition.js` 的轉場語言。
- **UI 規則**：沿用 Refillit OS 的斜切板塊。**文字不能被切到，也不能疊在一起**。

## 10. 技術（草案）

### 新增的程式
| 位置 | 內容 |
|---|---|
| `src/data.js` | `CARDS`、`FOES`、`COMMISSIONS`、`NODES`、`DRINK_FX`、`GEAR` |
| `src/battle/` | 戰鬥規則，**純邏輯、固定種子的亂數**，之後伺服器可以重播驗證 |
| `src/ui/battle.js` | 戰鬥畫面（B 版） |
| `src/ui/board.js` | 委託板和出門前選隊 |

### 存檔
- `state.tickets {n, day}`：外出券。
- `state.outing {round, commission, seed, node, deck, chill, temp}`：進行中的外出日。
- `state.collection {cards, gear, materials}`：永久收集。

### 伺服器檢查（`src/authority.js`，`supabase/functions/game` 要重新部署）
- 外出券：最多 3 張，每天最多 +1。
- 外出那一輪：店的營收必須是 0，薪水也是 0。
- 每格的獎勵有上限：看委託表和店等級，跟現在檢查研習券的做法一樣。
- 委託的種子由伺服器發。

### 平衡
- `BALANCE_VERSION` 要升到 12。
- `offline.js` 要認得公休的輪次：那一輪沒有營收、沒有薪水，房租照扣。

## 11. 實作順序（草案）

1. **戰鬥原型**（2026-10-21 做好，沒接經營）：
   - 規則：`src/battle/engine.js`。資料先放 `src/battle/data.js`，沒動 `data.js`，接經營時再搬。
   - 畫面：`src/ui/battle.js`、`src/ui/battle.css`。
   - 入口：網址加 `?battle`（本機測試用 `?battle&offline`），或除錯面板（反引號鍵）的「Battle prototype」。
   - 測試：`node tools/test/battle_test.js`，用自動出牌跑 300 次。目前自動勝率約 82%，夜間約 75%。
   - 第一場對手是通知和帳單，第二格是咖啡站，第三場 Boss 是鬧鐘加通知。

   原本的規劃：先不接經營。B 版畫面，4 個角色各 3 張卡，鬧鐘、通知、帳單三隻怪物，一張固定的委託。目標是**確認好不好玩**，順便用 `?offline` 在本機測。
2. **外出日**：委託板、外出券、公休一輪、金錢獎勵、伺服器檢查、`BALANCE_VERSION` 12。
3. **探索和收集**：分岔地圖、居民事件、素材和配方、器具、卡牌解鎖、恢復顏色的裝潢掉落。
4. **擴充**：Oritokki 和其他 5 位的卡、更多怪物、星期一 Boss、掃蕩、夜間和雨天修正。
